# mdbook-pdf2

This is a renew of mdbook-pdf to create a PDF file from mdbook without use of browsers.

## Projects related

- [`mdbook-compress`](https://github.com/v-nxe/mdbook-compress): The starting point of this project
- [`genpdf-rs`](https://github.com/dabega/genpdf-rs): A library that use printpdf and is used by mdbook-compress
- [`printpdf`](https://github.com/fschutt/printpdf): The creator of PDF files under the hood
